Good to know

A few clear answers.

What to expect from the beta.

Do I need a MyLimits account or server?

No. MyLimits runs locally in your browser. Website readers use your existing provider login; GitHub Copilot uses a token you explicitly provide.

Which tools can I track?

Claude / Claude Code, ChatGPT / Codex and Cursor have beta website readers. GitHub Copilot premium requests use the official GitHub REST API with a fine-grained Plan: read token. Coverage depends on your plan and the data each provider exposes. Real Copilot-token acceptance remains pending.

Does it show every ChatGPT chat limit?

No. The ChatGPT website reader focuses on the Work / Codex allowance. Ordinary chat quotas are separate, and missing limits are not estimated.

Will it keep tracking after I sign out?

Website tracking requires the current browser login. Previously seen accounts remain as dated cards; they do not independently refresh while signed out. Copilot uses its own token for each account and does not use the website session. Tokens can expire or be revoked. Closing the browser pauses collection.

Are saved sign-ins available?

Not in the current production policy. Website saved-sign-in vaults remain disabled. Copilot tokens are a separate opt-in REST connection and do not enable saved website sign-ins.

Does MyLimits read my conversations?

It does not collect prompts or conversations. Selected account and usage interfaces provide identity and normalized usage. Copilot data comes only from official GitHub REST endpoints, without cookies or scraping.

Why is a reading stale or a reset unknown?

A provider may not expose the value, a login may expire, or a check may fail. Last successful readings keep their age. For remembered website accounts, a passed reset may display a clearly marked projection; it is not a provider-confirmed quota or a new history reading.

Is my data encrypted?

Ordinary readings, nicknames, history and settings are local but not encrypted by MyLimits. Copilot tokens are encrypted separately with a non-extractable AES-GCM key. Privacy mode hides screen content and disables history export; it does not encrypt ordinary records.

How do I delete an account’s data?

Use Forget account to remove its local readings, nickname and history. Copilot Disconnect and Forget delete the relevant encrypted token. Uninstalling removes browser-owned extension storage. Revoke the token on GitHub separately if desired. See the deletion instructions.

How do I report a problem?

Open a GitHub issue. Include your browser, extension version and a description of the problem. Do not post tokens, cookies, sign-in links or private account exports.
