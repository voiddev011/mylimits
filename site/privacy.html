Privacy notice for the MyLimits extension.

Updated 24 October 2026 · Reviewed against version 3.4.0

No MyLimits account or server is required. The extension sends no analytics or advertising data and uploads no readings, history, nicknames, settings or credentials to MyLimits. It communicates directly with the providers you choose.

What is read

Claude, ChatGPT and Cursor website readers request selected identity, plan, workspace and usage data through your existing login. Copilot requests identity and premium-request usage only through api.github.com, without cookies, website endpoints or scraping. MyLimits does not collect prompts or conversations, or send model requests to measure limits.

What stays locally

  • Account state: normalized readings, plans, salted account IDs, display names, aliases, source metadata, private workspace routing IDs, refresh timestamps and settings.
  • History: real usage readings in IndexedDB, retained for 30 or 90 days. Projected resets never enter history.
  • Supporting records: migration recovery, notification deduplication, recovery budgets and sanitized diagnostics.

Ordinary records are not encrypted by MyLimits. Privacy mode hides names and history and disables export. Remembered website cards retain dated readings; a projected reset is clearly marked as an assumption.

Tokens and saved sign-ins

A Copilot connection stores your fine-grained Plan: read token separately in mylimits:tokens:v1, encrypted with AES-GCM and a non-extractable key in IndexedDB. Tokens never enter account state, history, exports, diagnostics or logs. Each token has its own connection and refresh schedule. This storage protection requires a supported browser API; unsupported token setup fails closed.

Website login cookies remain managed by the browser and provider. A ChatGPT bearer token, when needed, is used transiently for its usage request and never persisted. The separate website saved-sign-in implementation remains disabled for every provider. Copilot tokens do not change that policy. Encryption cannot protect against malware or someone controlling your browser profile.

Network requests

Provider requests use only approved HTTPS origins: claude.ai, chatgpt.com, cursor.com and api.github.com. No remote synchronization service or native helper is part of this version. Closing the browser pauses tracking.

This static website has no analytics, cookies, remote fonts or third-party scripts. GitHub Pages handles ordinary hosting requests under GitHub’s privacy statement. Following external links opens that service.

Every extension permission, explained

This describes normal builds, not the separate evidence spike. Provider hosts and optional permissions are requested only for the corresponding action.

Permission Purpose
storage Local settings, readings and connection state.
alarms Eligible refresh and maintenance scheduling.
scripting Selected usage interfaces in a permitted existing or recovery tab.
idle Eligible refreshes when the device becomes active.
sidePanel (Chromium) The browser side panel; omitted on Firefox.
Optional notifications Approved usage and reset alerts.
Optional cookies Narrow website sign-in presence/change signals. Copilot does not request cookies.
Optional exact HTTPS hosts The three website origins above and the official GitHub API origin.

Normal builds have no mandatory host grants, general browsing-history, native-messaging or web-request permission. Dormant saved-sign-in header rules remain gated off. Firefox declares no data collection; real Copilot token setup on Firefox is unverified.

Optional background-tab recovery

An eligible failed website check may open one inactive normal provider tab using your existing login. Recovery is rate limited, avoids private tabs and can be disabled in Settings. It cannot sign in for you or guarantee logout survival. If you activate its tab, MyLimits leaves it open.

Delete your data

  • Forget account: removes that account’s local readings, nickname, history and matching recovery records. Forgetting a remembered account leaves the current browser account working.
  • Copilot Disconnect or Forget: deletes the relevant encrypted token. Disconnect keeps dated readings; Forget also removes history. Revoke the token separately on GitHub to end its provider-side authorization.
  • Clear history: deletes the selected account’s or all accounts’ history after confirmation, while keeping tracking preferences.
  • Uninstall: removes browser-owned extension storage and IndexedDB. It does not sign out of provider websites or uninstall applications you installed in older versions.

Contact and source

Questions or privacy requests: GitHub issues. Keep credentials and private account data out of public issues. This notice is based on the current source code, including the manifest configuration, storage, recovery and vault policy.
