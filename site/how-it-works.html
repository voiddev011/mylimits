A clearer view.

MyLimits brings reported allowances together so you can spend less time checking dashboards.

01 / Choose what to connect

Install the extension, open MyLimits, and choose a provider from +. Approve access only to the websites you choose. Website tracking uses the account already signed in to that browser; you do not create a MyLimits account.

02 / Read the provider’s numbers

MyLimits checks selected account, session and usage interfaces. Depending on the source, it shows available allowances, reset times, plan information and the age of a reading. It does not send prompts or use model inference to measure your balance.

03 / Keep the useful context

Give accounts nicknames, review local history, and optionally approve notifications. Readings and settings stay in your browser by default. History retention can be set to 30 or 90 days. You can forget an account when you no longer want to track it.

When a reading needs a browser visit

A provider can reject a background check or require a fresh sign-in. Optional automatic recovery can briefly open one inactive normal tab using your existing browser login. It is rate limited and can be turned off in Settings. It cannot complete an interactive challenge or guarantee that a session survives logout.

Remembered accounts and Copilot tokens

When you switch a website login, MyLimits remembers the previous account and detects the new one. Only the current browser login refreshes; remembered cards keep dated readings. A projected reset is a display assumption, not a confirmed reading.

GitHub Copilot uses a separate fine-grained token for each account, with Plan: read permission. Paste it into MyLimits after choosing + → GitHub Copilot. Tokens are encrypted locally and checks run at most every 15 minutes. No separate application is needed. Copilot setup and current limitations.

Install the beta ZIP

  1. Open the homepage download area and download the Chrome ZIP for Chrome / Edge or the Firefox ZIP. If no release is available yet, the beta has not been published.
  2. Chrome / Edge: extract the ZIP. Open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.
  3. Firefox: open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on…, and select the extracted manifest.json. Temporary add-ons are removed when Firefox restarts. Permanent installation requires a Mozilla-signed package / store listing.
  4. Open MyLimits and connect a provider. Sign into that provider normally if prompted.

Browser readers are beta integrations. Provider changes, expired sessions and unavailable plan data can leave a reading stale or unknown. GitHub Copilot premium-request tracking is a beta REST integration; real-token acceptance remains pending.
